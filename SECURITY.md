# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

**Please do NOT create public issues for security vulnerabilities.**

Report vulnerabilities via email to: **security@kigulls.dev**

What we need:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

What we promise:
- Acknowledgment within 48 hours
- Assessment within 7 days
- Fix or workaround as soon as possible
- Credit in the release notes (if desired)

## Scope

- MQTT publish/receive via MCP protocol
- WebSocket + TLS transport
- Message handling and topic subscriptions

Out of scope: Infrastructure bugs not specific to kigulls-mqtt-mcp.
