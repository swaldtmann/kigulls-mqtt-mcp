# Git-Regeln

- Commit-Nachrichten IMMER auf Deutsch.
- Format: `typ(bereich): beschreibung`
- Beschreibung beginnt mit Kleinbuchstaben.
- Keine Punkte am Ende.
- Beispiel: `feat(api): endpunkt fuer status hinzugefuegt`
- Typen: feat, fix, refactor, docs, test, chore
- Remote: Codeberg (nicht GitHub).
