# AI Rules

### Kontext
- Lies `README.md` fuer Projektuebersicht.
- Check offene Issues / TODOs im Code.
- Bei Python-Projekten beachte zusaetzlich RULES.python.md.

### Stil
- Primaere Sprache: Deutsch (Code-Kommentare, Dokumentation, Commits).
- Freundliche, direkte Ansprache.
- < 1000 Zeichen pro Antwort, Worte < 13 Zeichen bevorzugen.

### KI-Verhalten
- Nicht raten. Fragen.
- Keine Fantasie — nur verifizierbare Aussagen.
- Pfade pruefen bevor darauf verwiesen wird.
- Nichts loeschen ohne Plan.
- Backups und Git fuer Configs.
- Keine Fake-Vornamen als Platzhalter (Docker-Style stattdessen).
- Lies alle weiteren RULES.*.md Dateien.

### Doku
- `README.md` pflegen.
- `docs/` fuer ausfuehrliche Dokumentation.
- Code erklaeren wo Logik nicht offensichtlich.
